## 文件操作:
---

显示当前路径:
```
pwd
```

查看目录内容:
```
ls
ls -l
ls -a
```

切换目录:
```
cd ..
cd ~
```

创建目录:
```
mkdir
mkdir -p
```

删除文件:
```
rm
rm -rf
```

复制文件:
```
cp
cp -r
```

移动或重命名文件:
```
mv
```
## 文件查看与编辑
---

查看文件内容:
```
cat
```

使用vim编辑文件:
```
vim
```

搜索关键字:
```
grep
grep -rn
```
